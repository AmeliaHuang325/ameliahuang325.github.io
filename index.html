    Research RAG Assistant 2026

    Technical lead

    An LLM assistant built on retrieval-augmented generation (RAG). It searches 441 research papers with semantic embeddings, then Claude writes a cited, evidence-grounded answer for planners and policymakers, with a confidence score. Answer quality is tested with LLM-as-judge evaluation.

    A paper-level retrieval change raised context recall from 25% to 65% on a 21-question expert benchmark.

    Case study Claude (AWS Bedrock) · Cohere embeddings · Qdrant · FastAPI · React · EC2

  • Mancala AI: Comparing Game-Playing Agents 2026

    Penn State, AI 801 · team project

    A from-scratch Mancala engine with five agents (Random, Greedy, Minimax, Alpha-Beta, MCTS), compared in a 9,408-game tournament across 30 configurations.

    Alpha-beta pruning ran 16× faster than minimax at depth 6 with no loss in playing strength.

    Code Python · game-tree search · Elo ratings

  • Solar Irradiance Forecasting with LSTMs 2026

    Penn State, AI 570 · team project

    Next-hour forecasting of direct normal irradiance for Tucson from 27 years of hourly NREL data, comparing four LSTM designs (univariate vs. multivariate, daytime-only vs. all hours).

    The LSTMs cut forecast error roughly in half compared with a persistence baseline.

    Code Python · TensorFlow/Keras · scikit-learn · pandas

  • Fire Detection with YOLO 2025

    An end-to-end object detection pipeline: image labeling, XML-to-YOLO annotation conversion, GPU fine-tuning of YOLOv8 and YOLO11, evaluation and inference on unseen images.

    mAP50 of 0.88 on the held-out test set with precision 1.00.
